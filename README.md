# About

Typecade is a minimalistic and professional typing platform designed to enhance your typing speed and accuracy. It features a robust real-time typing engine, comprehensive analytical tracking, and competitive mechanics. Typecade prioritizes a "Cyber-Minimalism" aesthetic by stripping away distractions, presenting infinite scrolling text generation, and providing instant visual feedback on precision and tempo.

# Features

- Highly accurate core typing engine processing inputs in real-time
- Dynamic content generation with infinite scrolling and text wrapping
- Multiple languages support (English and Indonesian modes)
- Modifiers for alphanumeric text generation (Punctuation and Numbers)
- Aesthetic "Cyber-Minimalism" interface completely free of distractions
- Smooth caret and 60fps hardware-accelerated transitions
- Comprehensive analytics tracking cumulative time, WPM, and accuracy history
- SEO-ready Server/Client component architecture

# Architecture

This project is built using modern web development standards and a robust technology stack:

- **Framework**: strict separation of Server and Client components using Next.js 16+ (App Router)
- **Styling**: Tailwind CSS v4 utilizing scoped design tokens
- **State Management**: Zustand for predictable state logic
- **Animations**: Framer Motion
